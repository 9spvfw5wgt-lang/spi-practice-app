# SPI練習アプリ

SPI言語対策用のシンプルなWebアプリです。

## できること

- 10問 / 15問 / 30問で出題
- 分野別に出題
  - 二語の関係
  - 語句の意味
  - 空欄補充
- ボタンで回答
- 最後に採点
- 間違えた問題だけNotion用にコピー
- 学習履歴をブラウザに保存

## 使い方

1. `index.html` をブラウザで開く
2. 出題数と分野を選ぶ
3. スタート
4. 最後に採点
5. 間違えた問題をNotionに貼る

## GitHub Pagesで公開する方法

1. GitHubで新規リポジトリを作る
2. このフォルダの中身をアップロード
3. Settings → Pages
4. Branchを `main` / `/root` にして保存
5. 表示されたURLを開く
